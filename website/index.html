The Harness,
in a window.

A thin native shell that starts the official DeepSeek Harness Web UI on your machine and opens it as a desktop app. No browser tabs, no port juggling, no manual dsh web.

Download Source on GitHub

Requires Node.js ≥ 18 — the app starts Harness through npx.

What the shell does

Starts itself

On launch it probes 127.0.0.1:3080. If Harness is already running, it attaches — and never starts a second backend. Otherwise it launches dsh web and waits for readiness.

One instance

A second launch just focuses the open window. No duplicate processes, no port fights — the single-instance lock sees to that.

Survives crashes

If the backend exits, the app offers to restart it instead of showing a dead page. Backend logs live one menu click away.

Stays local

Harness listens only on the loopback interface. The renderer runs sandboxed — no Node integration — and external links open in your browser.
